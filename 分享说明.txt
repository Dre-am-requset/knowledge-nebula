Knowledge Nebula · 知识星云

这是可直接发给他人的源码与公开演示包，采用 MIT 许可。
演示知识由项目自编，不是实际飞书聊天，不含个人笔记、账户或数据库导出。

接收者使用方法：
1. 解压 ZIP，进入 knowledge-nebula 文件夹。
2. 安装 Python 3.10 或更新版本。
3. Windows 双击 start.cmd；macOS/Linux 运行 sh start.sh。
4. 自行在浏览器打开 http://127.0.0.1:8768/。
5. 保持启动终端运行；关闭终端或按 Ctrl+C 可以停止服务。

此包使用 Python 标准库、SQLite 和随包附带的 Three.js。
无须安装 MySQL，无须登录飞书，无须提供模型 API Key。
真实三维界面支持拖动、缩放、点击知识星和主动开启巡航；截图仅用于说明。

首次运行会在本地 data/ 创建演示数据库；学习笔记和人工整理也写入该目录。
再次运行保留已有数据；运行时不会访问别人的本机飞书数据库或登录配置。

包内：源码、288 条自编演示知识、48 份示例资料、8 篇总结与学习路线、
启动入口、说明、测试、MIT 许可、Three.js 原始许可及发布文件哈希清单。
包外：真实群聊、文档与附件、作者身份、个人笔记、SQLite/MySQL 数据、
登录信息、Cookie、token、日志、Git 历史与远端配置。

导入你自己的资料：按 README.md 中的 JSON 格式准备文件，放入 data/。
分享给别人之前，使用 tools/package_release.py 重新打包，不要把整个运行目录
连同 data/ 一起压缩；打包器只收录明确列出的公开源码文件。

本包不会创建 GitHub 仓库或将资料上传到任何平台。
详细使用说明与数据格式见 README.md。
